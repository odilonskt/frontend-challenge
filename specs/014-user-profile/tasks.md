# Tasks: Perfil do colecionador que acompanha a conta

**Input**: Design documents from `/specs/014-user-profile/`

**Prerequisites**: plan.md, spec.md, research.md (D1–D12), data-model.md, contracts/ (`profile-endpoints.md`, `account-endpoints.md`, `constitution-amendment-1.9.0.md`), quickstart.md

**Tests**: Incluídos. A constituição (Princípio VII) exige E2E Playwright por página contra os mocks, com falhas e snapshots visuais, e a API precisa de verificação própria (o Playwright nunca aponta para `apps/api`). SC-001 ("outro navegador") só se prova pelo roteiro da API e pelo passo manual do quickstart.

**Organization**: Tarefas agrupadas por história de usuário (spec.md US1–US3). A API (`apps/api`) e o site (`apps/web`) são entregues em duas PRs independentes (o site só usa mocks), ver "Mapeamento para PRs".

## Format: `[ID] [P?] [Story] Description`

- **[P]**: pode rodar em paralelo (arquivos diferentes, sem dependência de tarefa incompleta)
- **[Story]**: US1–US3 da spec.md
- Todos os caminhos são relativos à raiz do repositório.

## Regras que valem para todas as tarefas

- **Sem `any`** em TypeScript (use `unknown` com estreitamento, genéricos ou os tipos dos contratos); o lint impõe.
- **SOLID/DDD explícito**: regra de negócio no serviço, Prisma só no adaptador (porta `ProfileRepository`), contextos delimitados separados (conta em `domains/auth`, perfil em `domains/profile`), um domínio só importa outro pela API pública dele (`@/domains/<domínio>`, como `ledger` já importa `auth`).
- **Fronteiras (Princípio I)**: `shared/` não importa `app/`, `pages/` nem `domains/`; páginas só importam domínios por `@/domains/<domínio>`; uma página não importa outra.
- **`apps/api` e `server/`**: `server/`, `apps/web/src/domains/orders`, `apps/web/src/domains/ledger` e `apps/web/src/domains/coins-admin` **não mudam** nesta feature.
- Mensagens ao usuário em português, as mesmas de hoje (data-model.md, "ProfileFieldCode").

## Path Conventions

API em `apps/api/`; site em `apps/web/`; docs em `docs/` e `specs/014-user-profile/`.
